GUIDE PHOTOS

Changer 70 photos sans toucher au code

Le site est prévu pour 10 images PNG par catégorie.

Principe

Chaque catégorie possède son propre dossier dans assets/images/products/. Pour remplacer une photo, gardez simplement le même nom de fichier.

colliers/colliers-01.png → colliers-10.png
manchettes/manchettes-01.png → manchettes-10.png
chaines-taille/chaines-taille-01.png → chaines-taille-10.png
parures-buste/parures-buste-01.png → parures-buste-10.png
boucles-oreilles/boucles-oreilles-01.png → boucles-oreilles-10.png
ensembles-couple/ensembles-couple-01.png → ensembles-couple-10.png
bijoux-corps/bijoux-corps-01.png → bijoux-corps-10.png

Pour changer un prix, un nom ou une pierre

Éditez seulement data/products.json. Aucun HTML n’est à modifier.

Pour ajouter une catégorie

Ajoutez un dossier d’images, 10 PNG, puis ajoutez la catégorie dans data/catalog.json et ses produits dans data/products.json.

Format conseillé

PNG vertical, idéalement 1200 × 1500 px, même ratio pour toute la boutique.
